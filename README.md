# Academic Research Agent
An AI-powered multi-agent academic research assistant that automatically discovers, analyzes, ranks, and summarizes scholarly literature using Large Language Models (LLMs).
The system combines academic search engines, intelligent planning, paper processing, relevance ranking, and automated report generation into a unified research workflow.

## Features
### Research Planning Agent
Converts research questions into optimized academic search queries
Generates multiple search strategies
Improves literature coverage

### Retrieval Agent
Searches across multiple academic sources:
Google Scholar (via SerpAPI)
arXiv

#### Capabilities:
Automated paper discovery
Metadata extraction
Duplicate removal
Multi-source aggregation

### Processing Agent
Cleans retrieved paper data
Generates concise paper summaries
Standardizes research outputs

### Ranking Agent
Evaluates paper relevance to the research question
Sorts results by importance
Prioritizes high-value literature

### Reporting Agent

Generates structured research reports including:
Research Overview
Key Findings
Literature Summary
Recommended Papers
Research Insights
Research Journal

## Tracks:
Search queries
Papers retrieved
Agent decisions
Generated reports

### Gradio User Interface
#### Provides a simple web-based interface for:
Submitting research questions
Viewing ranked papers
Reading AI-generated reports
