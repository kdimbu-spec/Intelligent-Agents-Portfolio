# Unit 2: First Order Logic

## Learning Summary

This unit introduced First Order Logic as a formal approach for representing knowledge and relationships within intelligent systems.

## Key Concepts

- Predicates
- Variables
- Constants
- Quantifiers
- Logical relationships
- Universal quantification
- Existential quantification

## Logical Expressions

An example of a First Order Logic expression is:

∀x(Student(x) → StudiesAgents(x))

This expression states that all students study intelligent agents.
