# Intelligent Agents – Learning Outcomes

The Intelligent Agents module has four learning outcomes.

## Learning Outcome 1

Identify and critically analyse agent-based systems, differentiating between architectures and approaches.

### Evidence

Evidence demonstrating this learning outcome will include:

- Agent architecture comparisons
- Reactive agent analysis
- Deliberative agent analysis
- BDI architecture analysis
- Hybrid architecture analysis
- Collaborative discussion contributions
- Relevant unit activities

---

## Learning Outcome 2

Apply and critically evaluate intelligent agent techniques to real-world problems, particularly where technical risk and uncertainty is involved.

### Evidence

Evidence demonstrating this learning outcome will include:

- Agent-system design activities
- Real-world problem analysis
- Practical agent exercises
- Risk and uncertainty analysis
- Final project design and evaluation
- Testing and implementation evidence

---

## Learning Outcome 3

Deploy critically appropriate software tools and skills for the design and implementation of an agent-based system, bearing in mind applicable legal, social, ethical, and professional issues.

### Evidence

Evidence demonstrating this learning outcome will include:

- Software development activities
- Agent implementation
- Programming/code
- System architecture
- Development tools
- Testing
- Ethical analysis
- Legal and professional considerations

---

## Learning Outcome 4

Systematically develop and implement the skills required to be an effective member of a development team in a virtual professional environment, adopting real-life perspectives on team roles and organisation.

### Evidence

Evidence demonstrating this learning outcome will include:

- Discussion forum participation
- Team exercises
- Team meeting notes
- Peer feedback
- Contributions to collaborative activities
- Communication evidence
- Team roles
- Leadership and teamwork activities

---
